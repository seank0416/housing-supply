# 유효 주택공급 지표 (40㎡ 초과)

지역별 주택 **인허가·분양·준공·착공·미분양**을 전용 40㎡ 이하 소형을 뺀 "유효 물량" 기준으로 보는 웹페이지입니다.
데이터는 국가통계포털(KOSIS) 국토교통부 통계를 매일 자동으로 받아옵니다.

## 데이터 출처 (KOSIS, 국토교통부 orgId 116)

| 탭 | 통계표 | 40㎡ 초과 계산 | 제공 기간 |
|---|---|---|---|
| 인허가 | DT_MLTM_1952 주택규모별 인허가실적(월별 누계) | 전체 − 40㎡ 이하 (누계→월 환산) | 2007.1~ |
| 착공 | DT_MLTM_5388 주택규모별 착공실적(월계) | 전체 − 40㎡ 이하 | 2011.1~ |
| 준공 | DT_MLTM_5374 주택규모별 준공실적(월계) | 전체 − 40㎡ 이하 | 2010.7~ |
| 분양 | DT_MLTM_5557 분양실적(공동주택, 순계) | **규모 구분 미제공 → 전체** | 2013.1~ |
| 미분양 | DT_MLTM_2080 규모별 미분양현황 | 전체 − 40㎡ 이하 | 40㎡ 구분은 2021.11~ |
| 준공 후 미분양 | DT_MLTM_5328 공사완료후 미분양현황 | 전체 − 40㎡ 이하 | 40㎡ 구분은 2021.11~ |

- 수도권·지방은 시도 합산(수도권 = 서울+인천+경기, 지방 = 전국 − 수도권)으로 만듭니다.
- 광주·전남은 통합 발표('전남광주') 이전 기간을 광주+전남 합산으로 이어 붙였습니다.
- 검증: 인허가 2026년 1~9월 누계 전체 189,873 / 40㎡ 이하 13,321 / 40㎡ 초과 176,552호, 준공 2026년 1~8월 150,664 / 12,233 / 138,431호 (KOSIS 원표와 일치).

## 구조

```
index.html               화면 (정적 페이지, 서버 불필요)
data/housing.json        수집된 데이터 (자동 갱신)
data/_fetch_log.json     마지막 수집 기록
scripts/fetch_kosis.py   KOSIS 수집 스크립트 (파이썬 표준 라이브러리만 사용)
.github/workflows/update.yml   매일 10시·16시(KST) 자동 수집 → 변경 시 커밋 → GitHub Pages 배포
```

## 수동으로 갱신하기

- 웹: GitHub 저장소 → Actions → "데이터 갱신 및 배포" → **Run workflow**
- 로컬: `config.json`에 `{"kosis_api_key": "키"}` 저장 후 `python scripts/fetch_kosis.py` → `python -m http.server 8000` → http://localhost:8000

웹페이지의 **최신 업데이트** 버튼은 저장소에 반영된 최신 데이터를 다시 불러옵니다(KOSIS를 직접 호출하지 않음).

## 키 관리

KOSIS 인증키는 GitHub 저장소 **Settings → Secrets → Actions → `KOSIS_API_KEY`** 와 로컬 `config.json`(업로드 제외)에만 있습니다.
